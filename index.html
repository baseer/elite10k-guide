Comparison notes & sources +

This guide compares the selected weapons release with the user-designated original Elite B19. Values were extracted from their assets and checked against the active weapon/projectile inheritance and relevant scripts. Stock UT means the base game behavior that B19 uses for that setting. For explosive splash, the B19 comparison includes the inherited 20-damage minimum; its flak ball overrides the maximum to 95.

All times are in game seconds at the default fire-rate multiplier. Server game speed, armor, amplification, saved settings, and other mutators can change actual results. Projectile timings are illustrations of configured behavior, not network measurements.

The full-screen HUD is a separate optional package. Weapon overlays, load rings, and projectile effects are described separately. The guide focuses on the differences you will notice when moving from B19 to Elite10K.
