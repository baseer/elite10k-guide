New contributors and agents: read AGENTS.md and [onboarding](docs/ONBOARDING.md).
The mod repository provides package reconstruction, editor setup and current
recipe/source locations. This repository owns the static guide and publication.

```powershell
node verify-history.cjs
node verify-movement.cjs
node verify-neutral-gap.cjs
node verify-current-release.cjs
python -m http.server 8000
```

Visit http://localhost:8000/. No frontend build or npm installation is required
for these numerical checks. Browser checks use separately installed Playwright:
`node verify-current-browser.cjs http://localhost:8000/`.

The archive covers 48 weapons releases from v1.57 through v2.05. Version labels
retain game spelling (v1.6, v1.7, v1.8 and v2.0). Historical same-version
revisions are preserved under versions/VERSION/revisions. This update preserves
all 47 earlier release snapshots and archives the initial v2.05 ring-opacity revision.

comparison-data.json and its JS wrapper contain current defaults; versions-data.js
supplies selected models; versions/releases.json indexes provenance and parameters.
See docs/ONBOARDING.md for the complete source map and synchronized-data workflow.
Native Flak decay uses age: distance figures assume constant speed and are not
accumulated flight-distance measurements. Runtime claims follow recorded release
receipts; this site update does not run new game tests or a full source recook.

Sections have real directory entry points generated by `node build-routes.cjs`
from index.html. Regenerate them after root-shell changes. Relative base paths
support both local preview and the /elite10k-guide/ GitHub Pages prefix. Tools
preserve their inputs and selected profiles in shareable URLs; test that behavior
when changing navigation. GitHub Pages publishes main. Check the Pages build
and live content after an authorized push.

Earlier detailed update notes are preserved in docs/HISTORICAL_NOTES.md. The old
chatgpt.site deployment and old test counts there are historical provenance.

Final v2.05 rocket-ring default opacity is 0.925 (92.5%); existing saved custom opacity values remain local preferences.
